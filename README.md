# Keunju Song — GitHub Pages homepage (draft)

A lightweight research portfolio built with plain HTML/CSS/JavaScript. No Jekyll, npm, or external theme dependency is required.

## Files

- `index.html` — main research portfolio
- `publications.html` — full publication list
- `assets/styles.css` — responsive layout + light/dark theme
- `assets/script.js` — mobile menu, theme toggle, subtle reveal animation

## Preview locally

From this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy to GitHub Pages

For a user-site repository named `KeunJuSong.github.io`, place these files at the repository root and publish the default branch with GitHub Pages.

> This draft was intentionally prepared separately from the existing repository, so the live site is not changed until the design/content is reviewed.

## Content notes

The first draft was migrated from the public Google Sites profile and publicly linked research pages. Before final deployment, consider checking:

1. current Ph.D./employment title after graduation,
2. publication status for manuscripts currently under review,
3. whether to add a portrait and downloadable CV,
4. whether to expose all patents or keep only selected items,
5. any new 2026 publications/projects not yet listed on Google Sites.
